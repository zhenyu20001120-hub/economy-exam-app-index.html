## 1. 这个应用是干什么的

中级经济师（工商管理）考试的特点是：**考点细、范围广、题量大**。单纯看教材很容易「看了忘、记不住」，而直接刷整套模拟卷又容易「以考代学、错一堆还不知道为什么错」。

本应用的设计理念是 **「以题促学」+「三轮闭环」**：

1. **做题即学**：每一道题都不是孤立的，点「提交」后立刻告诉你对/错，并展开**三层解析**（选项逐项讲透 → 出题思路 → 本章知识点回顾 / 思维导图），同时点明**本题对应的知识点**属于第几章。
2. **错题自动沉淀**：答错的题自动进入「错题本」，随时专攻薄弱点。
3. **三轮学习闭环**：用「三轮学习」把 11 章题库**按章节顺序**逐章过三遍（每轮 ≥160 题、三轮互不重复、累计覆盖全库），基础扎实后再去「模拟真题」做全真检验。

适合人群：自学者、在职备考、想用碎片时间（手机）刷题的人。

## 4. 五大导航 & 各模块详细用法

### 4.1 首页（学习主页）

打开应用默认进入首页，展示：

- **顶部统计**：已学题数、正确率、错题数（实时统计）。
- **🎯 三轮学习进度卡**：显示第 1 / 2 / 3 轮各自的正确率，点一下进入三轮学习选择页。
- **四个模式按钮**：
  - 📚 **章节练习**：按考纲 11 章逐章刷（详见 4.2）。
  - ❌ **错题练习**：只刷答错的题，清空错题本。
  - 🎲 **随机练习**：随机抽样强化记忆。
  - 📝 **模拟真题**：全真机考（详见 4.5）。
- **金色 🎯 三轮学习卡片**：本次应用的核心入口（详见第 6 节）。
- **📊 查看章节进度**：进入章节进度页。
- **⚙️ 云同步与设置**：进入同步设置（详见第 8 节）。
- **重置学习数据**：清空本机进度与错题（不可恢复，会二次确认）。

### 4.2 章节练习

- 从「章节进度」页选择某一章，进入**逐题作答**。
- 每题点「提交答案」即判对错并展开解析（与三轮学习相同的反馈机制，见第 5 节）。
- 用「上一题 / 下一题」翻题；支持键盘 **← / →** 翻题。
- 顶部显示「第 X / 总 题」，已做的题会在章节进度页标记。

### 4.3 错题练习

- 自动收集所有答错的题（多选题只要漏选/错选即计入错题）。
- 进入后逐题重做，做对后从错题本移除。
- 错题本为空时会有提示「还没有错题，先去练几题吧」。

### 4.4 随机练习

- 从全库随机抽样，用于考前突击、强化记忆。
- 同样支持逐题提交反馈。

### 4.5 模拟真题（全真机考）

这是**唯一计时**的模式，完全模拟真实考场：

- **组卷**：自动生成 100 题 = 单选 60 题（每题 1 分）+ 多选 20 题（每题 2 分）+ 案例分析 20 子题（每题 2 分），满分 **140 分**，及格 **84 分**（60%）。
- **限时**：**90 分钟**倒计时，顶部实时显示剩余时间；时间到自动交卷。
- **机考体验**：
  - 顶部固定信息条（已答 / 总题、倒计时、交卷按钮）。
  - **答题卡**（📋）：点开可总览所有题作答状态，点题号直接跳转。
  - 多选题部分选对给 0.5 倍分、全对给满分（与官方规则一致）。
- **交卷结果**：
  - 得分卡（得分 / 满分 / 及格线 / 用时）。
  - **错题回顾**：列出所有错题，点开内联展开「三层解析」。
  - 「返回首页 / 再来一套」。

> 模拟真题与三轮学习是**两条独立路径**：模拟真题走「整卷交卷评分」；三轮学习走「逐题提交反馈」。互不干扰。

## 5. 「逐题提交即判对错」机制详解

不管是章节练习、错题练习、随机练习，还是三轮学习，**每一道题都采用「边做边学」的反馈机制**：

1. 选择答案（单选点选，多选可多选），点 **「提交答案」**。
2. 立即：
   - ✅ / ❌ 提示本题对错；选项直接**标绿（正确项）/ 标红（你错选的项）**。
   - 展开 **💡 本题对应知识点** 卡片：一句话点明这题考的是什么、属于第几章。
   - 展开 **三层解析**：
     - **① 选项解析（逐项讲透）**：对每个选项对/错的原因逐一说明。
     - **② 出题思路**：这道题在考什么、怎么辨析易混概念。
     - **③ 知识点回顾与讲解**：本章知识回顾 + 详细讲解 + 可展开的**思维导图**。
3. 提交后本题**锁定**（选项不可再改），可回看解析；用翻题键继续下一题。
4. 答错的自动进错题本；顶部进度条实时更新「已学 N / 总 · 正确率 %」。

> 设计目的：不是「做完一整卷才知道错哪」，而是**每做一题就立刻闭环**，把错的当场搞懂。

## 6. 三轮学习（核心功能）

「三轮学习」把「复习」改成了「学习」——**不是做三轮卷子，而是以做题来加强学习，边做边学。**

### 6.1 进入方式

首页金色卡片「🎯 三轮学习」→ 选择轮次（第 1 / 2 / 3 轮）。

### 6.2 每一轮怎么学

- **按章节顺序**：题目按第 1 章 → 第 11 章排序，从头到尾学一遍（不是随机混排）。
- **不计时**：顶部明确标注「🕊 不计时 · 按章节顺序」，自由作答，不卡时间。
- **每轮 ≥ 160 题**：覆盖工商管理所有细节考点（不止 11 个大章标题，每个细节考点都会轮到）。
- **逐题反馈**：每题点「提交」即判对错 + 知识点 + 三层解析（与第 5 节完全一致）。
- **本轮正确率**：学的过程中顶部实时显示「已学 N / 总 · 正确率 %」。
- 答错的自动进「错题本」，学完一轮可去「错题练习」专攻。

### 6.3 三轮之间如何安排

- **第 1 轮（首轮）**：通学全库，建立整体印象。
- **第  ️2 轮（巩固）**：换一批未做过的题（三轮跨轮去重），加深记忆。
- **第 3 轮（冲刺）**：再过一批新题，三轮累计**覆盖整本题库 502 题**。
- 每一轮抽到的题**互不重复**；若三轮都做完，再点会从头重新抽（可手动「重置三轮历史」）。

### 6.4 完成一轮后

点最后一题的「完成本轮」按钮（不是交卷，是学完本批题）→ 显示**本轮学习情况**：

- 本轮已学题数、正确数、正确率。
- 提示「答错的题已自动加入错题本」。
- 引导进入**下一轮**，或（三轮学完后）直接去 **📝 模拟真题**检验水平。

> 一句话：**三轮学透（边做边学）→ 再去模拟考（整卷计时）**，形成完整备考闭环。

## 8. 云同步与多设备

应用默认**只在当前浏览器本地**保存进度（localStorage）。如需**跨设备**（手机 + 电脑）记住进度与错题，可开启云同步：

- 进入「⚙️ 云同步与设置」。
- 开关打开，填入你的 **GitHub Personal Access Token**（`ghp_xxx` 或 fine-grained token）和仓库名。
- 应用会：
  - **自动备份**：每次做题/交卷后把进度写入你指定仓库的 `ee-sync` 分支（一个 JSON 文件）。
  - **自动恢复**：进入应用时若云端有更新的进度，自动拉取合并。
  - 也可手动「备份到云端 / 从云端恢复」。
- **多人分享互不干扰**：分享给朋友时，各自用不同的「用户名」前缀，错题和进度**分开记录、互不覆盖**。

> Token 仅保存在你本机浏览器，不会被任何人读取；仓库为你自己所有，数据可控。
> 不开通云同步也能完全正常使用，只是进度只留在本机。

## 9. 进度与错题数据存在哪

- **本机存储**：浏览器 `localStorage`，以当前「用户名」为前缀（默认 `guest`），存：已做题、正确题、错题、收藏、三轮学习进度、最近位置等。
- **隐私模式友好**：在 Safari 无痕 / 隐私模式等 `localStorage` 不可写的环境下，应用会静默降级（不崩溃、仍能答题），只是进度不保存。
- **清空数据**：首页「重置学习数据」或设置页「清空本机学习数据」可一键清除（二次确认，不可恢复；云端文件不会自动删）。

## 10. 题库数据结构（开发者视角）

题库在 `build.py` 中以 Python 列表定义，每道题是一个字典，字段如下：

| 字段 | 含义 |
|---|---|
| `id` | 题号，如 `c1-1`（第 1 章第 1 题）|
| `chapter` | 所属章（1–11）|
| `type` | `single` 单选 / `multiple` 多选 / `case` 案例 |
| `stem` | 题干 |
| `options` | 选项数组 |
| `answer` | 正确选项下标数组（单选长度 1，多选/案例可能多个）|
| `analysis` | 总体解析（可选，缺失时自动生成）|
| `oa` | 选项逐项解析数组（逐条讲每个选项）|
| `logic` | 出题思路（可选）|
| `kp` | 本题对应知识点（一句话，学习模式重点展示）|
| `real` / `year` | 是否真题、真题年份（展示「真题」标签）|
| `case` / `subs` | 案例背景、案例子题（子题展开为独立练习项，带 `caseBg`）|

每章的「知识回顾 / 详细讲解 / 思维导图」放在 `DATA.mind[章节id]` 中（`review` / `detail` / `map` 三个字段）。

## 11. 技术架构

- **单文件交付**：最终产物是**一个 `index.html`**，内嵌全部 HTML / CSS / JavaScript 与题库数据，零外部依赖、可离线、可直接双击打开。
- **生成器**：`build.py`（Python 3）读取题库定义，渲染出 `index.html`。
- **纯前端**：无后端、无框架、无构建链；所有逻辑用原生 JavaScript 实现。
- **本地存储**：`localStorage` + 可选 GitHub API 云同步。
- **测试**：
  - `test_exam.js`：用 **jsdom** 真实加载 `index.html` 做集成测试（三轮学习逐题反馈、知识点展示、跨轮去重、三轮覆盖全库等）。
  - `test_harness.js`：轻量 smoke 测试，校验核心函数不抛错。

## 17. 常见问题 FAQ

**Q：手机能用吗？**
A：能。页面做了移动端适配，手机浏览器直接打开 Pages 链接即可刷题，底部有固定导航，按钮够大好点。

**Q：一定要联网吗？**
A：不需要。整个 `index.html` 是自包含的，离线也能用（只有「云同步」需要联网）。

**Q：三轮学习和模拟真题有什么区别？**
A：三轮学习是「边做边学」——每题提交立刻出对错和解析，不计时；模拟真题是「整卷模考」——100 题限时 90 分钟，交卷才出总分和错题。建议先三轮学透，再模考检验。

**Q：错题会一直留着吗？**
A：会，直到你在「错题练习」里做对才移除；也可在设置里一键清空。

**Q：三轮做完还能再练吗？**
A：能。三轮都做完后再进入会从第 1 轮重新抽题；也可在三轮学习页「重置三轮历史」重新来过。

**Q：数据会丢吗？**
A：本机数据存在浏览器 `localStorage`，换浏览器 / 清缓存会丢；建议开启「云同步」备份到自己的 GitHub 仓库。

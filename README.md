# 中级经济师 · 工商管理 刷题小程序

一个**自包含、零依赖、可离线**的网页刷题应用，专为「电脑 + 手机」个人刷题设计。
依据 **2026 版考纲（11 章，新增第 6 章《质量管理与安全生产管理》，删除原电子商务章）**
+ 近五年（2021–2025）真题命题规律整理，并收录 2024 真题样例。

## 功能（对标粉笔考公刷题架构）
- **章节练习**：按考纲 11 章逐章刷，首页可看每章进度。
- **错题练习**：只刷历史答错的题；答对后自动移出错题集。
- **随机练习**：随机抽样 30 题强化。
- **模拟真题**：全真 100 题（单选 60 + 多选 20 + 案例分析 20），限时 90 分钟，交卷出分（84 分及格 / 140 满分），并列出错题可回顾解析。
- **题目解析**：无论答对答错，提交后立即给出标准答案与知识点解析；真题题目标注「真题」。
- **本地进度**：练习记录、正确率、错题集全部存在浏览器 `localStorage`，**不上传、不联网**。
- **云同步（跨设备记忆，可选）**：在「⚙️ 云同步与设置」里开启后，进度会备份到你 GitHub 私有仓库的一个**不发布分支**（默认 `ee-sync`）。换手机/电脑打开同一网址会自动恢复「学到哪里」和「错题集」。Token 只存在你本机浏览器，**不进页面、不进仓库**。

> 题型与判分完全对齐官方规则：单选 1 分；多选错选 0 分、少选每正确项 0.5 分；案例分析（单选/多选混合）同理。

## 文件说明
- `index.html` —— **应用本体（交付物）**，所有题目与代码已内嵌，单文件即可运行。
- `build.py` —— 题库与界面的「源码生成器」。改题库或加题后运行 `python build.py` 重新生成 `index.html`。
- `test_harness.js` —— 仅用于开发期冒烟测试，日常使用无需关心。

## 使用方式（任选其一）

### 方式 A：电脑直接双击（最简单）
把 `index.html` 拷到任意位置，**双击用浏览器打开即可刷题**。无需联网、无需服务器。

### 方式 B：手机刷题（两种）
1. **部署到 GitHub Pages（推荐，最方便）**：见下方「部署到 GitHub Pages」。
2. **离线文件**：把 `index.html` 通过微信/数据线传到手机，用手机浏览器（或「文件」App）打开即可。
   - 注意：手机端用 `file://` 打开时，进度只存在该手机浏览器里。

### 方式 C：本地起一个服务（可选，便于手机同 WiFi 访问电脑）
```
cd 本目录
python -m http.server 8080
```
手机与电脑连同一 WiFi，手机浏览器访问 `http://<电脑局域网IP>:8080/`。

## 部署到 GitHub Pages（电脑 + 手机随时访问）
1. 在 GitHub 新建一个**私有仓库**（免费账户也支持私有库 + Pages；公开库也可，只要你**不分享链接**就只有自己用，页面已加 `noindex` 不被搜索引擎收录）。
2. 把本目录的 `index.html` 上传到仓库根目录（即仓库里要有 `index.html`）。
3. 仓库 `Settings → Pages → Build and deployment → Source` 选 **Deploy from a branch**，分支选 `main` / `master`，目录选 `/ (root)`，保存。
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
5. 电脑、手机都用这个网址刷题。默认进度保存在各自设备浏览器里（无后端）。想**跨设备自动记住进度与错题**，按下面「云同步」开启。

## 云同步（跨设备记住进度与错题）
> 原理：GitHub Pages 是静态托管，本身没有存储。云同步把你的进度写成仓库里的一个 JSON 文件，应用通过 GitHub API 自动读/写它（serverless 数据库模式）。

**一次性准备（约 3 分钟）：**
1. 新建一个 GitHub **私有仓库**专门存进度，例如 `ee-exam-data`（也可以复用上面的应用仓库）。
2. 在该仓库建一个分支 **`ee-sync`**（不要用 Pages 的发布分支，否则进度文件会被公开托管出去）。
   - 做法：`ee-exam-data` 仓库页面 → 切到默认分支 → 在分支下拉框输入 `ee-sync` → 回车创建。
3. 生成 Token：仓库 `Settings → Developer settings → Personal access tokens → Fine-grained token`（或 Classic token），权限**只勾这个仓库的 Contents: Read and Write**。复制 token。

**在应用里开启：**
1. 打开应用 → 首页点「⚙️ 云同步与设置」。
2. 打开开关 → 填：仓库 `owner/repo`（如 `johnny/ee-exam-data`）、Token、数据分支 `ee-sync` → 保存。
3. 保存后会**立即备份一次**到云端；之后每次练习自动防抖上传（约 1.5 秒后）。
4. 在另一台设备打开同一网址 → 进设置填同样的仓库/Token/分支（Token 只存本机）→ 点「从云端恢复」，或直接靠打开时自动拉取，进度与错题即同步。

**安全提示：**
- Token 仅存于你本机浏览器的 `localStorage`，**绝不写入 `index.html` 或提交到仓库**，所以公开页面不会泄露。
- 旧版「进度分别保存在各自设备」仍然成立；开启云同步后改为以云端为准（按时间戳最后写入胜出）。
- 想彻底退出：设置里关掉开关即可，云端文件可手动在仓库里删。

## 如何扩充 / 修改题库
编辑 `build.py` 里的 `add(...)` 调用（或新增 `add(...)` 行），保存后运行：
```
python build.py
```
即可重新生成 `index.html`。题目字段：
- 普通题：`add(题号, 章节号, "single"|"multiple", 题干, [选项], [正确选项下标(0起)], 解析, real=是否真题, year=年份)`
- 案例题：用 `"case"` 类型，传 `case="背景文字"` 与 `subs=[{子题...}]`（子题结构同普通题）。

## 重置学习数据
应用首页底部有「重置学习数据」按钮，可一键清空进度与错题。
